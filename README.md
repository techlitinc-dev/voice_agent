# voice_agent

Monorepo aggregating three projects:

- **CRM-AI-V2** — CRM with AI capabilities
- **dograh** — Dograh HQ application
- **vaani-ai** — Voice AI platform (Next.js + Prisma)

## Structure

```
voice_agent/
├── CRM-AI-V2/   # CRM-AI-v2 (from github.com/techlitinc-dev/CRM-AI-v2)
├── dograh/      # Dograh (from github.com/Dograh-hq/dograh)
└── vaani-ai/    # Voice AI (from github.com/Dograh-hq/vaani-ai)
```

## Setup

Each project has its own environment and dependencies. See each subdirectory's README/docs for setup instructions. Copy `.env.example` to `.env` where applicable — `.env` files are never committed.
